from sklearn.cluster import KMeans៖ ទញយក (Import) ម៉ាូឌ្ុល KMeans ព្ី Library scikit-
learn ឈៃើមបីយកមកឈត្ែើត្បាស់សត្មាែ់ការឈធវើ Clustering ។   
import pandas as pd៖ ទញយក Library pandas ឈដ្ឋយដ្ឋក់ឈ្មោះឈៅឈត្ៅថា pd សត្មាែ់
ត្គែ់ត្គង និងវិភាគទិនន័យ ។   
df=pd.read_csv('customers.csv')៖ អានឯកសារទិនន័យត្ែឈភទ CSV បៃលមានឈ្មោះថា 
customers.csv រួែរកាទុកវាឈៅកនុងែបត្មែត្មួល (Variable) ឈ្មោះ df (DataFrame) ។   
print(df)៖ ែងាាញទិនន័យទំងអស់បៃលបានអានព្ីឯកសារ CSV ឈនាោះឈៅឈលើ Screen ។

ឃ្លៃទី២៖ 
  X=df.drop('CustomerID', axis=1)៖ លុែជួរឈរ (Column) បៃលមានឈ្មោះថា 'CustomerID' 
ឈែញព្ី DataFrame df ឈត្រោះអតតសញ្ញាណ ID មិនបមនជ្ជលកខណៈព្ិឈសស (Feature) សត្មាែ់យក
ឈៅែងវឹក Model ឱ្យែងត្កុមឈ ើយ ($axis=1$ មានន័យថាឈធវើការឈៅឈលើជួរឈរ)។ លទធនលបៃលឈៅ
សល់ត្តូវបានរកាទុកកនុងត្ែថាែ់ X ។  
  print(X)៖ ែងាាញទិនន័យ X បៃលបានលុែ Column 'CustomerID' រួែរល់។ 
 
ឃ្លៃទី៣៖ 
model=KMeans(n_clusters =3, random_state =42)៖ ែឈងកើត Object រែស់ KMeans Model 
ឈដ្ឋយកំណត់ែំនួនត្កុមបៃលែង់ែងគឺ ៣ ត្កុម (n_clusters=3) និងកំណត់ random_state=42 ឈៃើមបី
ធានាថាការរត់កូៃឈៅឈព្លឈត្កាយៗឈទៀតនឹងនតល់លទធនលៃបៃល (មិនបត្ែត្ែួលដែៃនយ) ។  
label=model.fit_predict(X)៖ ែញ្ាូនទិនន័យ X ឈៅឱ្យ Model ឈធវើការគណនាបែងបែកត្កុមនង និង
ទញយកលទធនលដនត្កុម (Labels ៃូែជ្ជ $0, 1, 2$) មកលាក់ទុកកនុង Variable ឈ្មោះ label នង។  
print(label)៖ ែងាាញលទធនលត្កុមបៃលទសសន៍ទយបានសត្មាែ់រល់អតិែិជននីមួយៗ (ែងាាញជ្ជ 
Array ដនឈលខត្កុម) ។ 
 
ឃ្លៃទី៤៖ 
df['Cluster']=label៖ ែឈងកើតជួរឈរែមីមួយឈ្មោះថា 'Cluster' ឈៅកនុង DataFrame df ឈៃើម ឈដ្ឋយ
ដ្ឋក់តដមៃជ្ជឈលខត្កុម (label) បៃលឈទើែនឹងទទួលបានព្ី Model ។   
print(df)៖ ែងាាញទិនន័យ df សារជ្ជែមី បៃលឈព្លឈនោះមានែបនែមជួរឈរត្កុមអតិែិជន (Cluster) ឈៅ
ខាងែុង ។

DataFrame ឈ ើងវិញ ឈដ្ឋយបនាកឈលើតដមៃឈៅកនុងជួរឈរ 'Cluster' (ព្ីត្កុមទី 0 ៃល់ទី 2) រួែរកាទុក
